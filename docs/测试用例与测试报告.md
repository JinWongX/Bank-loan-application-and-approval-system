# 银行贷款申请与审批系统 — 测试用例与测试报告

## 1. 测试环境

| 项目 | 说明 |
|---|---|
| 操作系统 | Windows 10/11 |
| JDK | 11（兼容 1.8+） |
| Maven | 3.9.x |
| 后端框架 | Spring Boot 2.7.14 |
| 测试框架 | JUnit 5 + Spring Boot Test + MockMvc + MyBatis-Plus |
| 数据库 | SQLite（测试使用独立文件数据库 `loan_system_test.db`） |
| 测试配置文件 | `backend/src/test/resources/application.yml` |
| 测试数据文件 | `backend/src/main/resources/data.sql` |
| 测试执行命令 | `mvn test` |

说明：测试配置中启用了 MyBatis-Plus 逻辑删除，并指定了测试专用初始化数据 `data-test.sql`，以保证统计、合同、放款等场景具备稳定可预期的测试数据。

### 8.6 修复的业务缺陷

在编写端到端测试过程中，发现并修复了审批退回补充的状态流转缺陷：

- **问题**：审批人执行 SUPPLEMENT 动作后，原代码将状态设置为 `DUE_DILIGENCE_COMPLETED`，导致客户经理无法重新提交尽调报告（尽调要求状态为 `CREDIT_EVALUATED`）。
- **修复**：将审批 SUPPLEMENT 动作后的状态改为 `MATERIAL_SUPPLEMENT`，与客户补充材料入口保持一致，形成完整闭环。
- **影响文件**：
  - `backend/src/main/java/com/bank/loan/service/impl/ApprovalServiceImpl.java`
  - `backend/src/test/java/com/bank/loan/ApprovalServiceTest.java`
